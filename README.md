# Draseis Planner

Πρόσθετο (plugin) για WordPress που διαχειρίζεται τις προτάσεις σχολικών δράσεων και το πρόγραμμα δράσεων του **5ου Γυμνασίου Χανίων**.

Οι εκπαιδευτικοί υποβάλλουν πρόταση δράσης μέσω φόρμας. Η διεύθυνση εκπαιδευτικού ελέγχεται με σύνδεση μέσω ΠΣΔ (Πληροφοριακό Σύστημα Δημόσιας Διοίκησης). Η διεύθυνση της διαχείρισης βλέπει τις υποβολές, τις εγκρίνει ή τις απορρίπτει και τις καταχωρίζει στο ημερολόγιο.

## Λειτουργίες

- Φόρμα υποβολής δράσης, με υποχρεωτικά πεδία και έλεγχο προθεσμίας (εργάσιμες ημέρες, χωρίς αργίες).
- Πίνακας «Πρόγραμμα δράσεων» με φίλτρο τάξης, εμφάνιση παλαιότερων δράσεων και επισήμανση της επόμενης ημέρας.
- Διαχείριση υποβολών στον πίνακα διαχείρισης του WordPress: έγκριση, απόρριψη, ακύρωση.
- Αυτόματη καταχώριση εγκεκριμένων δράσεων σε Google Calendar (μέσω λογαριασμού υπηρεσίας).
- Εξαγωγή εγκεκριμένων δράσεων σε αρχείο CSV, ως αντίγραφο ασφαλείας.
- Ρυθμίσεις: προθεσμία υποβολής, αργίες, πεδία και τύποι δράσεων.

## Shortcodes

| Shortcode | Τι εμφανίζει |
|---|---|
| `[draseis_planner]` | Τον πίνακα δράσεων (πρόγραμμα δράσεων) |
| `[draseis_planner_form]` | Τη φόρμα υποβολής δράσης |
| `[g5d_proposals]` | Τη σελίδα υποβολών, με έλεγχο πρόσβασης |

Το παλιό shortcode `[programma_draseon]` λειτουργεί ακόμη, για συμβατότητα.

## Εγκατάσταση

1. Κατεβάστε το αρχείο `draseis-planner.zip` από τη σελίδα [Releases](../../releases).
2. Στο WordPress, πηγαίνετε στο **Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση πρόσθετου** και ανεβάστε το αρχείο.
3. Ενεργοποιήστε το πρόσθετο.
4. Συμπληρώστε τις ρυθμίσεις στο μενού **Draseis Planner** (σύνδεση ΠΣΔ, Google Calendar, προθεσμία, αργίες).

## Απαιτήσεις

- WordPress 6.0 ή νεότερο
- PHP 7.4 ή νεότερο
- Λογαριασμός υπηρεσίας Google με πρόσβαση στο ημερολόγιο του σχολείου
